# Compatibility

> "Runs Windows programs" is the goal, not the current state. This page explains
> exactly what that sentence will mean, and what stands between here and there.

---

## Today

| Thing | Runs? |
|---|---|
| Spotlight NT kernel in QEMU | ✅ |
| Spotlight X desktop | ❌ (does not exist yet) |
| Any `.exe` | ❌ |
| Microsoft drivers | ❌ |
| Windows userland | ❌ |

There is no compatibility layer hiding in the repository. The kernel prints its
boot log on COM1, exercises 44 NT syscalls, runs a CPL3 PE32+ test image and then
halts. The compatibility layers, userland and application corpus are still ahead.

---

## What "compatible" will mean

Compatibility is a contract, enforced at four boundaries:

| Boundary | Contract |
|---|---|
| **Syscall ABI** | `LSTAR` entry, `EAX` = number, first argument in `R10`, shadow space, `NTSTATUS` in `RAX` |
| **PE/COFF** | sections, relocations, imports, TLS, SEH tables (`.pdata`/`.xdata`) |
| **Structures** | `TEB`, `PEB`, `KUSER_SHARED_DATA`, `EPROCESS`, `ETHREAD` at documented offsets |
| **Semantics** | handles, wait states, APC delivery, section mapping, access checks |

A program does not "almost work". It either finds the contract intact or it
crashes — which is why every contract in `spotlight-nt/docs/05-abi` has a test.

## The two tracks

### Track B — our userland (main line)

* Our `ntdll`: PE loader, heap, syscall stubs, SEH, TLS.
* Win32 layer: `kernel32`, `user32`, `gdi32`, `advapi32`, … adapted from Wine
  (LGPL-2.1+) where the licence allows, replaced over time.
* A corpus of 20 real programs (7-Zip, Notepad++, PuTTY, Git, Python, curl,
  ffmpeg CLI …) with per-program checklists.
* Result: ordinary `.exe` files on our kernel. This is **L3**.

### Track A — Microsoft userland (research)

* Real `smss.exe`, `csrss.exe`, `winlogon.exe`, `explorer.exe`.
* Real drivers: `acpi.sys`, `pci.sys`, `storport.sys`, `ntfs.sys`, `win32k.sys`.
* The user brings their own licensed Windows installation; the project ships no
  Microsoft files.
* Result: proof of ABI accuracy, **L4–L5**, gated by G2.

`win32k.sys` alone — shadow SSDT, GDI objects, `KeUserModeCallback` — is the
largest single risk in the project, which is why Track A is not the release path.

---

## What we will not ship

* Microsoft binaries, hives, fonts, or ISOs.
* Patched Microsoft drivers.
* Anything derived from leaked source code.
* A "compatibility mode" that silently returns success for unimplemented calls.
